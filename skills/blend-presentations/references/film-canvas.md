# Film variant (canvas 1920x1080), documented only

Not generated by `build_deck.py`. Use it only when the user asks for an animated "film" instead of a slide deck.
No canonical share is used as a reference for this variant; it is a documented pattern only.

- One `<canvas width=1920 height=1080>` scaled to the viewport with CSS (`object-fit: contain`, navy letterbox).
- Render is a pure function `draw(t)` of time in seconds; a `requestAnimationFrame` loop advances `t`; scenes are
  `[start, end, fn]` entries. No state outside `t`, so seek and replay are trivial.
- Reuse the same tokens (read them once with `getComputedStyle(document.documentElement)`), the logo as an inline
  SVG positioned top-right over the canvas, weight 400 only.
- Controls: Space play/pause, ArrowLeft/Right seek +/-5 s, Home/End, R replay, F fullscreen, `#t=12` hash seek.
- Must keep: `prefers-reduced-motion` (render the final frame of each scene, no loop), `@media print` (print a
  static poster frame), `aria-label` on the canvas plus a hidden text transcript of the narration.
- Validation: `validate_presentation.py` expects `.slide` elements, so a film fails E4/E6 by design; run the core
  `validate.py --kind presentation` instead.
